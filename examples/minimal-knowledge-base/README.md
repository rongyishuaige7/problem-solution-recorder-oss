# Minimal problem-solution knowledge base (example)

This directory is a **mirror** of the bundled template shipped with the skill at:

`skill/problem-solution-recorder/assets/minimal-knowledge-base/`

It exists so GitHub visitors can browse a complete example (records, indexes, patterns, reviews) without opening the skill subtree.

To create your own live knowledge base from the same template:

```bash
skill/problem-solution-recorder/scripts/init-kb.sh "$HOME/problem-solution-kb"
export PROBLEM_SOLUTION_KB_ROOT="$HOME/problem-solution-kb"
```

For a per-project marker file, see [`.problem-solution-root.example`](.problem-solution-root.example).
