# Media

## dashboard.png

The dashboard screenshot used in both READMEs. It is rendered from a **fictional demo
knowledge base** (7 records, 3 patterns, 1 review), not from a real one — no private
troubleshooting data is embedded in the image.

- Size: 1440 × 900
- Source: `web/index.html` of a knowledge base generated by `psr init`
- Capture: headless Chrome, 3 s virtual time budget

### Reproduce

```bash
# 1. A demo knowledge base with fictional records
psr init /tmp/demo-kb
psr configure --global /tmp/demo-kb

# 2. Add a few records covering solved / workaround / unresolved,
#    a couple of patterns, and one review, then copy the dashboard:

# 3. Generate and capture
node /tmp/demo-kb/web/generate-data.js
open /tmp/demo-kb/web/index.html          # eyeball it once

"/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" \
  --headless=new --disable-gpu --no-sandbox \
  --window-size=1440,900 --virtual-time-budget=3000 \
  --screenshot=docs/media/dashboard.png \
  "file:///tmp/demo-kb/web/index.html"
```

Re-shoot when the dashboard layout changes; keep the image free of real records.
