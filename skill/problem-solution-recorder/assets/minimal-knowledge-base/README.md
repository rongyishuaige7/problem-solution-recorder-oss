# Problem-Solution Knowledge Base

This repository records solved issues so both humans and AI agents can reuse the lessons.

Start with:

```text
AI入口.md
```

Core files:

- `records/YYYY/*.md`: full solved issue records
- `INDEX.md`: human-readable index
- `AI_SUMMARY_INDEX.md`: compact AI recall index
- `_templates/问题记录模板.md`: canonical record template
- `AI记录提示词.md`: copyable prompts for other AI tools
- `AI工具记录规则.md`: global rule snippets and completion hook
- `patterns/`: reusable troubleshooting patterns
- `reviews/`: daily, weekly, and monthly reviews
